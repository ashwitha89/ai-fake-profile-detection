# 🔍 AI Fake Profile Detection

A Machine Learning based web application that detects fake social media profiles using behavioral and profile-based features.

---

## 📌 About the Project

Fake profiles on social media are a growing concern. This project uses Machine Learning algorithms to classify whether a social media profile is **real or fake** based on various profile attributes.

Built as part of B.Tech CSE (AI/ML) coursework.

---

## ✨ Features

- 🔎 Detects fake vs real profiles using ML
- 📊 Analyzes profile features like followers, posts, bio, etc.
- 🌐 Web interface built with Flask
- ⚡ Fast and lightweight

---

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Language | Python |
| ML | Scikit-learn |
| Backend | Flask |
| Frontend | HTML, CSS, JavaScript |

---

## ⚙️ How to Run

```bash
# 1. Clone the repository
git clone https://github.com/ashwitha89/ai-fake-profile-detection.git

# 2. Go to the project folder
cd ai-fake-profile-detection

# 3. Install dependencies
pip install -r requirements.txt

# 4. Run the app
python app.py
```

Then open your browser and go to: `http://localhost:5000`
